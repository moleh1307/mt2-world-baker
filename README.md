# Original Pyungmoo tree baker

Reviewable Windows-only preparation tool. Downloads16 original `.spt` recipes, the original SDK header/import library and a SpeedTreeRT DLL from pinned public repositories in `sources.json`. Builds the upstream GPL tree baker, validates its measured leaf-card formula and returns baked geometry as a short-lived Actions artifact.

No game files, player saves, screenshots, local paths or private notes are uploaded. A new public repository and a single standard Windows Actions run (maximum5 minutes) require separate user approval before publishing/running. The downloaded DLL has not been executed locally.
